# 灵同步 · 多平台内容同步测试版

一次整理动态正文、图片和标签，在同一个工作台选择平台并同步，减少反复复制粘贴。内容草稿保存在本地；支持有序附件、超长正文转图片、固定标签、星球与圈子选择，以及独立的平台任务记录。

[下载安装包](https://github.com/674180795-dotcom/ling-sync/releases/download/v0.2.14-dev.5/ling-sync.zip) · [版本说明](https://github.com/674180795-dotcom/ling-sync/releases/tag/v0.2.14-dev.5)

当前版本 **0.2.14-dev.5**，优先完善动态发布。适配入口覆盖微信公众号、知识星球、即刻、小红书、X、B站、抖音、快手和视频号。**九平台尚未全部完成稳定发布验收**，部分任务需要到平台核对结果。

## 安装与使用

1. 下载测试版 `ling-sync.zip`，解压到固定目录，根目录应包含 `manifest.json`。
2. 在 Ego Lite 中打开 `chrome://extensions`，启用开发者模式，选择「加载未打包的扩展程序」，指定解压目录。
3. 点击灵同步图标打开侧栏，填写正文、图片和标签，连接所需平台并授予对应站点权限。平台使用当前浏览器的正常登录状态。
4. 选择平台后开始同步。开启直接发布会尝试发送；关闭时仅填写到原生编辑器，按任务记录检查结果。

新打开或刷新侧栏从空白内容开始，同一会话收起再展开保留当前输入；旧稿通过历史入口加载。文章和视频保留既有实现，本版本不新增其验收承诺。

## 当前验证范围

本轮即刻 B2 已完成扩展自动公开核对。X 和知识星球 B2 均由扩展执行发送，正常页面出现完整样本；X 成功回执捕获、知识星球公开图片核对仍有缺口。小红书取得提交回执，视频号有管理页记录；公众号确认、快手话题、B站旧测试稿恢复等仍需继续验证。

「已填写」只表示编辑器内容已核对；「已提交」表示取得提交回执；「已发布」要求公开结果核对。「待核对」可能已发送成功，请先打开原任务检查，避免重复发布。新转图任务按原附件、文字卡片页码排列；旧任务与附件不会因升级自动重发。

## 本地开发

需要 Node.js 24.11+ 的 24.x 版本。

```sh
npm ci
npm run typecheck
npm test
npm run build
npm run verify
```

构建生成 `dist/` 和 `release/0.2.14-dev.5/ling-sync.zip`，仅构建 MV3 扩展，不启动浏览器。当前 36 文件、368 项内部测试通过。真实浏览器验收使用 Ego Lite，内部测试通过不等于平台公开发布通过。

源码不依赖参考扩展或其服务端。按需授予平台站点权限；本地草稿、浏览器认证信息及运行现场不随分发包上传。
